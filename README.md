# 专属小厨房 · 点菜网页

宿舍/情侣用的点菜小网页，纯前端，三个文件，不需要安装任何东西。

## 怎么打开

双击 `index.html`，用 Edge 打开就能点。

## 能做什么

- 默认菜单 59 道，分 **主食 / 荤 / 素 / 蛋 / 汤 / 喝 / 空气炸锅 / 未分类** 八类，广西家乡菜 + 广东常吃的 + 宿舍两口锅（电煮锅、空气炸锅）做得了的
- 冰箱里的默认食材按 **2026-11-15 晚超市小票** 录的，另加了 **11-14 拼多多买的海天调料 9 件套**（生抽 / 食用油 / 陈醋 / 料酒 / 盐 / 淀粉 / 蚝油 / 花椒粉 / 鸡精）
- **调料类不记数量**，用完直接在冰箱里点「删」那一行
- **每道菜的菜谱都写了放什么调料、放多少**（油、盐、生抽、料酒这类都单列在「食材」里，做法里也标明「半勺盐」「1 勺生抽」）；白米饭、速食粉、蒸南瓜、水煮蛋、热牛奶、烤紫薯这类本来就不用调料，做法里直接写「不用放调料」
- **点菜**：分类菜单、搜索、随机点菜、最近点单、购物车下单、备注
- **食记**：订单（待接单 / 制作中 / 已完成）、菜篮（单价总价、勾选已买、放入冰箱）、冰箱（**也就是全部食材账本**：加减数量、保质期、快过期 / 已过期 / 需补货）
- **厨房**：每道菜单独点「待接 / 制作中 / 已完成 / 取消」（取消的菜会把食材退回冰箱，也不会列进「这次怎么做」）、看这次要做的菜怎么做、催进货置顶、审核吃货上传的菜谱
- **我**：改名字、切换厨师/吃货身份、看统计、清空数据
- **点菜不设限**：冰箱里没有的菜也能点、能下单（有时只是想看看菜谱怎么做）；卡片上会提示「冰箱缺什么」，旁边可以「催进货」
- 下单时，冰箱里有的食材会自动扣掉数量；师傅把每道菜都点「已完成」后，这一单才算进「我」的小统计

## 数据存在哪

存在浏览器的 localStorage 里（key `diancai_v1`）。**换设备、换浏览器、清缓存都会丢，两台设备之间也不共享。** 想两个人互相看见，得接一个后端（Supabase 之类），后面再说。

## 放到 GitHub Pages

1. 在 GitHub 新建一个仓库，**选 Public**（免费开 Pages 必须是公开仓库）
2. 进仓库页面，点 **Add file → Upload files**，把 `index.html`、`style.css`、`app.js` 三个文件拖进去，底下点 **Commit changes**
   （不用 git，网页上拖就能传）
3. Settings → 左边 Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，Save
4. 等一两分钟刷新，访问 `https://<用户名>.github.io/<仓库名>/`

改版以后：进仓库 → 点开要换的文件 → 右上角铅笔图标 → 全选删掉粘新的；或者 Add file → Upload files 同一个文件名会覆盖。

> - 仓库公开 = 谁拿到网址都能打开这个网页，但每台设备的数据只存在自己浏览器里，别人看不到你的菜单和订单。
> - 从本地文件换成 `github.io` 以后，数据是全新的（本地那份带不过去）。想保留就先别清缓存，本地这份还能用。
> - 国内访问 `<用户名>.github.io` 有时会慢或打不开，这是网络问题，不是网页的问题。
